# DeepSeek 用量 · 任意时间段增强（Chrome 扩展）

让 DeepSeek 开放平台「用量」页（platform.deepseek.com/usage）支持 **任意时间跨度** 查询。

> 背景：官方页面与后端接口单次最多只允许查询 31 天（前端会提示「只支持查询最多 31 天的数据」）。
> 本扩展在浏览器本地拦截页面的数据请求，把大区间自动拆成多个 ≤31 天的分片拉取后合并，
> 再交还给官方界面渲染——总览卡片、图表、明细表都是 **原生组件的样子**，只是时间跨度不再受限。

---

## 一、安装（约 1 分钟）

1. 在电脑上新建一个文件夹，例如 `deepseek-usage-enhancer`；
2. 把下面两个文件保存进去（**文件名必须完全一致**，内容为 UTF-8 文本）：
   - `manifest.json`
   - `ds-usage-enhancer.js`
3. 打开 Chrome，地址栏输入 `chrome://extensions` 回车；
4. 打开右上角的 **「开发者模式」** 开关；
5. 点左上角 **「加载已解压的扩展程序」**，选择第 1 步的文件夹；
6. 刷新（或打开）https://platform.deepseek.com/usage ，筛选栏里「Export」旁会出现
   **「任意时间段」按钮**。

## 二、使用

- 点「任意时间段」→ 选择区间（快捷预设：近 3 个月 / 近 6 个月 / 近 1 年 / 全部；也可手动选择日期）→
  点 **「应用（刷新生效）」**。页面刷新后即固定显示该区间。
- **API Key 过滤**：在面板下拉里选择某个 Key；也可继续使用页面上原生的「API Key」筛选（两者联动）。
- **图表横向滚动**：长区间的图表（消费金额 / 请求 / Tokens）下方会出现 **横向滑动条**——
  左右拖动滑条、把鼠标放在图表上滚动 **滚轮**（向下滚 = 往回看更早的日期，向上滚 = 回到更近）、
  或按住拖动，都能平移查看更早的日期；Y 轴会自动适配当前显示范围。
- **导出 CSV**：按「天 × Key × 模型」的完整明细（日期、请求数、输入缓存命中/未命中 token、输出 token、费用、币种），
  文件带 BOM，Excel 直接打开不乱码。
- **恢复原生**：一键回到官方默认行为（最多 31 天）。
- 若之后在页面上手动改了「时间」筛选，增强视图会暂时让位给原生筛选（这是有意设计）；
  重新点「应用」即可再次生效。

## 三、说明与限制

- **只读**：仅查询你本人账号的用量数据，不修改账号与服务器；扩展**未申请任何额外权限**
  （Manifest 中没有 `permissions` 字段，仅通过内容脚本匹配 `platform.deepseek.com`）。
- 区间越长请求越多（每 31 天一片，`cost` / `amount` 各一次）：1 年 ≈ 24 个请求，通常几秒内完成。
- 时区跟随页面设置（默认 GMT+8）；数据最多延迟 5 分钟。
- 需要 **Chrome 111+**（Manifest V3 的 `world:"MAIN"` 特性；2023 年 3 月之后的版本均满足）。
- 若官方接口或前端结构大改导致增强失效，扩展会自动回退为原生请求，不影响页面正常使用。

## 四、常见问题

- **点了「应用」没反应？** 页面会刷新一次再生效；若刷新后外观没变，请确认筛选栏旁的按钮处于
  高亮（增强开启）状态，或再点一次「应用」。
- **数据看起来和 31 天差不多？** 如果你账号的用量集中在最近一个月内，长区间与 30 天的数字本来就相同；
  日期筛选标签会显示为自定义区间（如 `03/17 - 09/12`）以示区别。
- **想彻底卸载？** 在 `chrome://extensions` 中移除即可。建议先点「恢复原生」清理页面偏好，再移除扩展。

## 五、工作原理（简述）

扩展以「主世界（MAIN world）」内容脚本运行于页面上下文：

1. 拦截 `XMLHttpRequest`，识别官方发出的用量请求 `/api/v0/usage/by_api_key/{cost,amount}`；
2. 当增强模式开启、且页面筛选仍处于受控状态时，把目标区间拆为若干 ≤31 天的分片，逐片请求并
   合并为与官方接口完全同构的 JSON（含 `start/end/bucket/models/series` 等字段），
   并为区间内每一天补齐零值桶——官方图表在 >31 天时只会绘制「数据中实际出现的日期」，
   补齐后横轴即可覆盖完整区间；
3. 用本地 `Blob` URL 作为响应体“重放”该请求，让 XHR 完整走一遍原生生命周期；
4. 页面上的官方组件（KPI 卡片、图表、明细表）因此无感地渲染任意长度区间；
   扩展同时会把页面上的日期筛选标签回写为自定义区间样式，保持观感一致；
5. 图表由 ECharts（SVG 渲染）绘制，扩展通过 React fiber 定位图表实例并注入原生 `dataZoom`
   （底部滑动条 + 滚轮/拖动平移），长区间即可左右滚动浏览更早日期。

## 六、更新记录

- **v1.2.0**：修复「全部」定位最早日期不准的问题（改为逐窗口扫描 + 只认非零用量，可正确处理
  数据断档，例如 8/11~8/12 有数据、之后空白到 8/30 的情况）；滚轮改由扩展自行接管
  （官方 ECharts 构建未实现 `moveOnMouseWheel`），向下滚 = 往回看、向上滚 = 回到更近，
  且不再带动页面滚动。
- **v1.1.0**：图表支持横向滑动条 + 滚轮/拖动平移；Y 轴自适应；数据补齐每日零值桶，
  使图表横轴覆盖完整区间。
- **v1.0.0**：初版，任意时间段分片合并 + 官方界面原生渲染 + CSV 导出。
